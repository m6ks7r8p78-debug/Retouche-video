# Dépannage

| Problème | Solution |
|---|---|
| Page introuvable | Vérifie le R majuscule : …github.io/**R**etouche-video/ |
| « Qualité maximale indisponible » | L’app continue sans IA. Ouvre Modèles IA pour voir la raison ; recharge l’app si un fichier est signalé abîmé. |
| L’export s’arrête ou l’app se recharge | Mémoire de l’iPhone saturée : choisis Full HD ou une partie plus courte (Réglages → Partie à traiter). |
| Pas de son dans le résultat | Lis la ligne « Son » du compte rendu : la raison y est donnée. |
| L’IA est décochée sur une longue vidéo | Elle prendrait plus d’une heure : choisis un extrait, puis recoche « Qualité maximale ». |
| Le relief ne s’installe pas | Il faut internet la première fois (27 Mo). Modèles IA → « Réessayer » reprend où il s’était arrêté. |
| Besoin d’aide | Outils → « Copier le diagnostic pour Claude », puis colle-le dans la conversation. |
