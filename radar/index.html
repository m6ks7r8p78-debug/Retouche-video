YouTube

Obtenir la clé gratuite (5 min, sans carte bancaire)
  1. Dans Safari, ouvre console.cloud.google.com et connecte-toi avec un compte Google.
  2. En haut : Sélectionner un projet › Nouveau projet › nom « Radar » › Créer.
  3. Menu ☰ › API et services › Bibliothèque. Cherche YouTube Data API v3, touche Activer.
  4. Menu ☰ › API et services › Identifiants › Créer des identifiants › Clé API. Copie la clé (elle commence par AIza) et colle-la ici.
  5. Environ 100 recherches YouTube gratuites par jour.

Bluesky

Facultatif. Créer un mot de passe d'application
  1. Appli Bluesky › Réglages › Confidentialité et sécurité › Mots de passe d'application.
  2. Ajouter, nomme-le « RecherchVid’s », copie le code et colle-le ici. Jamais ton vrai mot de passe.

Serveurs fouillés et jeton d'accès

  2. Jeton : ouvre ton serveur dans Safari › Préférences › Développement › Nouvelle application, laisse seulement read, enregistre, copie Votre jeton d'accès.
