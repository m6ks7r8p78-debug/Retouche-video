YouTube

Comment obtenir la clé (5 min, sans carte bancaire)
  1. Dans Safari, ouvre console.cloud.google.com et connecte-toi avec un compte Google.
  2. En haut, choisis Sélectionner un projet puis Nouveau projet (nom : Radar).
  3. Menu ☰ › API et services › Bibliothèque, cherche YouTube Data API v3, touche Activer.
  4. Menu ☰ › API et services › Identifiants ›Créer des identifiants › Clé API. Copie la clé qui commence par AIza.
  5. Conseillé : touche la clé › Restrictions relatives aux API › coche seulement YouTube Data API v3 › Enregistrer.

La clé est gratuite et permet environ 100 recherches YouTube par jour (le compteur se remet à zéro chaque matin vers 9 h). Chaque appui sur « Lancer le radar » en utilise une seule, quel que soit le nombre de mots-clés.

Bluesky

La recherche publique marche sans compte. Connecter ton compte (gratuit) permet de lire ton propre fil avec « Mes abonnements » et rend la recherche plus fiable.

Créer un mot de passe d'application
  1. Dans l'appli Bluesky : Réglages › Confidentialité et sécurité › Mots de passe d'application.
  2. Touche Ajouter, nomme-le « Radar », copie le code affiché.
  3. N'utilise jamais ton vrai mot de passe ici : le mot de passe d'application peut être supprimé à tout moment.

Mastodon

Sans compte, l'appli cherche tes mots-clés sous forme de hashtags (#manifestation) sur ces serveurs.
Obtenir un jeton d'accès
  1. Ouvre ton serveur Mastodon dans Safari et connecte-toi.
  2. Préférences › Développement › Nouvelle application.
  3. Nom : Radar. Dans les autorisations, laisse seulement read coché. Enregistre.
  4. Ouvre l'application créée et copie Votre jeton d'accès.
