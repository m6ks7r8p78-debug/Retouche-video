Essai expérimental · traitements locaux

1. Choisir un souvenir

Le fichier reste sur ton appareil. Cette page ne l'envoie à aucun serveur. Les scripts et les poids IA sont téléchargés depuis ce site.

Choisis un média. Pour une vidéo, positionne la lecture sur l'image que tu souhaites tester, puis mets-la en pause.

2. Choisir le modèle IA

Modèle actif : sr.bin, ancien modèle. Pour essayer le nouveau modèle entraîné, importe d'abord RetoucheProAI_MODELE_PILOTE_PRIVE_V1.bin.

Le nouveau modèle est obligatoire. Restaurer ouvre directement Fichiers si nécessaire. Sur iPhone, choisis le fichier .bin enregistré dans Téléchargements : tous les fichiers sont visibles et la bonne empreinte est vérifiée automatiquement. Aucun traitement avec l’ancien modèle.

Sans fichier : modèle public sr.bin. Avec notre fichier .bin privé : nouveau pilote entraîné sur 5 vidéos, ×2 uniquement. Le fichier de poids reste sur ton iPhone ; il n'est pas envoyé au site.

Touche l'image pour choisir le centre de la zone. Le réseau traite les pixels d'origine, sans les réduire artificiellement avant le test. ×4 peut être plus lent.

Commence par importer une photo ou une vidéo. Le bouton Restaurer ouvre Fichiers si ton modèle privé n’est pas encore sélectionné.

Aucun média sélectionné.

4. Ton verdict

Après ton choix, copie le compte rendu et colle-le dans notre conversation ChatGPT pour que je puisse ajuster le projet. Aucune donnée n'est envoyée automatiquement. Le pilote privé n'est pas validé pour la restauration d'un film complet.
